# homelab

実運用を前提とした個人向けホームサーバー基盤。

Proxmox VE上にOPNsense、Discord Bot、ゲームサーバー、独立したネットワーク検証環境を構築する。構成と設定はGitで管理し、永続データ以外は再構築可能にする。

## 目的

- Discord Botからゲームサーバーを起動・停止・状態確認できる
- ゲームサーバーだけをインターネットへ公開する
- OSPFなどを検証できる、通常環境から完全分離したLabを用意する
- 構成・設定・ドキュメントをGitで管理する

## 状態

Phase 0B（PVE管理強化）と、ゲームVMを操作するDiscord Botを構築済み。ゲームサーバー、バックアップ、外部公開は実際にゲームを遊ぶ予定が決まった時点でまとめて実施する。
