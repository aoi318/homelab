# HomeLab 仕様書

## 1. 概要

### 1.1 目的

本システムは、実用性・拡張性・再現性を重視したホームサーバー基盤を構築し、以下の用途で利用することを目的とする。

* Discord Botのホスティング
* ゲームサーバーのホスティング
* ネットワーク技術（OSPF等）の検証環境

### 1.2 コンセプト

本システムは学習専用環境ではなく、実際に利用することを前提としたホームサーバー基盤とする。

必要最小限の機能から構築し、将来的な機能追加や拡張を容易に行える構成を目指す。

---

# 2. システム要件

## 2.1 MUST

### 仮想化基盤

* 仮想化基盤としてProxmox VEを利用すること

### Discord Bot

* Discord Botをホストできること
* Discord Botからゲームサーバーを起動・停止・状態確認できること

### ゲームサーバー

* ゲームサーバーをホストできること
* インターネット経由でゲームサーバーへ接続できること
* ゲームサーバー停止時にバックアップを取得すること
* バックアップは最新1世代を保持すること

### ネットワーク

* OSPF等のネットワーク検証環境を構築できること

### 構成管理

* 構成・設定・ドキュメントをGitHubで管理できること

---

## 2.2 SHOULD

* OPNsense等の専用ルーター／Firewallを導入できること
* VPN
* 監視システム

---

## 2.3 COULD

* NAS
* Git Server
* Kubernetes
* CI/CD
* 認証基盤
* ローカルAI

---

# 3. 完成条件

以下を満たした時点で HomeLab v1.0 の完成とする。

* Discord Botが利用可能であること
* Discord Botからゲームサーバーを起動・停止・状態確認できること
* ゲームサーバーをインターネット経由で利用できること
* OSPF等のネットワーク検証環境を利用できること

---

# 4. 利用者

| 利用者      | 利用内容                                |
| ----------- | --------------------------------------- |
| 管理者      | サーバー管理・OSPF検証・Discord Bot開発 |
| 友人        | ゲームサーバー利用                      |
| Discord Bot | ゲームサーバー制御                      |

---

# 5. 運用方針

* ゲームサーバーは基本1サーバーのみ同時稼働とする。
* ゲームサーバーの起動・停止はDiscord Botから実施する。
* プレイヤー不在時はセーフティネットとして自動停止を行う。
* 利用していないサービスは停止し、リソース消費を抑える。

---

# 6. データ保護方針

以下のデータを保護対象とする。

* ゲームワールドデータ
* Discord Botの設定・データ

以下は保護対象外とする。

* OS
* Dockerイメージ
* 一時データ
* キャッシュ

障害発生時は、システム全体の復元ではなく、環境の再構築とデータ復元を基本とする。

---

# 7. セキュリティ方針

* 外部公開は必要最小限とする。
* ゲームサーバーのみ外部公開を行う。
* 管理系サービスは外部公開しない。
* Discord Botは外向き通信を基本とする。

---

# 8. 品質要求

## 運用性

* 日常利用しやすいこと
* メンテナンスしやすいこと
* 障害発生時に復旧しやすいこと

## 拡張性

* 新しいゲームサーバーを容易に追加できること
* 新しいサービスを容易に追加できること
* ハードウェア更新時にも対応できること

## 再現性

* ドキュメントのみで環境を再構築できること
* GitHubで構成管理できること
* 構成・設定をコードおよび設定ファイルで管理できること
* 環境依存値は設定ファイル等へ分離すること

---

# 9. 制約条件

## ハードウェア

| 項目       | 内容               |
| ---------- | ------------------ |
| ホスト     | 既存のノートPC     |
| CPU        | 仮想化支援対応CPU  |
| メモリ     | 16GB（実質約14GB） |
| ストレージ | 512GB SSD          |
| Hypervisor | Proxmox VE         |

## システム

* 家庭内ネットワークで運用すること
* 物理サーバーは1台とする
* ストレージ容量を考慮した運用を行うこと

---

# 10. 対象外

以下は本仕様書の対象外とする。

* 高可用性（HA）
* クラスタ構成
* Kubernetes運用
* NAS構築
* エンタープライズレベルのバックアップ
* オフライン環境での構築

---

# 11. 設計指針

本システムは以下を基本方針とする。

* 実用性を最優先とする。
* 必要最小限の機能から構築する。
* 将来的な拡張を妨げない設計とする。
* 再構築可能なシステムを目指す。
* コード・設定ファイルによる管理を前提とする。
* YAGNI（You Aren't Gonna Need It）の考え方を採用し、現時点で不要な機能は実装しない。
